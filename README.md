# دومينو الصحاب
منصة ويب خاصة للأصدقاء (2–4 لاعبين) باستخدام Node.js وSocket.IO.

## التشغيل محليًا
1. ثبّت Node.js 18 أو أحدث.
2. افتح Terminal داخل المجلد.
3. شغّل `npm install` ثم `npm start`.
4. افتح http://localhost:3000.

## النشر أونلاين
ارفع المشروع إلى GitHub ثم أنشئ Web Service على Render أو Railway، بأمر بناء `npm install` وأمر تشغيل `npm start`. تحتاج استضافة Node.js تدعم WebSockets. بعد النشر افتح الرابط من أي جهاز وأنشئ غرفة وشارك كودها.

## ملاحظات
- الغرف خاصة بكود غير مدرج، لكنها ليست محمية بكلمة مرور.
- عند قطع الاتصال، يعود باقي اللاعبين للانتظار وتبدأ جولة جديدة؛ لا يوجد استرجاع جلسة.
- البيانات مؤقتة في ذاكرة السيرفر وتُفقد عند إعادة تشغيله.
- لا توجد قاعدة بيانات أو حسابات أو دردشة أو إعادة اتصال تلقائية.
